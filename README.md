# LinkPulse

Ek simple URL shortener website, Python aur Flask se bani hai.

## Features
- Long URL ko short link mein badalna
- Short link se original website par redirect
- Click count save karna
- Analytics table mein clicks dikhana

## Run karne ka tarika
1. `pip install flask`
2. `python app.py`
3. Browser mein `http://127.0.0.1:5000` kholo
